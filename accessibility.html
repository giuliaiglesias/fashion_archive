Accessibility

What this site does to be usable by as many people as possible, and where it falls short.

What has been done

  • Keyboard. Every link and button can be used with the keyboard, and the focus outline is always visible. The magazine on the home page opens with Enter or Space and closes with Esc. The Timeline moves between years with the arrow keys. The Quiz, Search and Mannequin Room are made of normal buttons and fields.
  • Skip link and structure. Each page starts with a “Skip to content” link and uses proper landmarks (header, navigation, main, footer) and one main heading, so screen readers can jump around.
  • Language. Every page declares that it is in English.
  • Contrast. Text and background colours were chosen to meet WCAG 2.1 level AA contrast, including the red accent and the dark sections.
  • Motion. If your device is set to reduce motion, the magazine, the cards, the Timeline and the Quiz stop animating.
  • Small screens. The pages adapt to phone width without sideways scrolling.
  • Not only colour. In the Quiz, correct and wrong answers are marked with the words “Correct” and “Your answer”, not just green and red. In the Mannequin Room each piece says “Put on” or “Take off”.
  • Announcements. The Search count, the Timeline year and the Mannequin Room look are announced to screen readers when they change.
  • Embedded videos have a title and a plain link to the same video on YouTube.
  • Without JavaScript. The pages with text still work. The interactive pages show a message with links to the main sections.

How it was checked

The automated accessibility tool axe-core was run on every page and found no violations when this page was written (November 2026). Automated tools only catch part of the possible problems, so the keyboard behaviour and the phone layout were also checked with scripted tests.

Known limits

  • The site has not yet been tested with a screen reader or with the browser zoomed to 200%.
  • The YouTube videos are third-party players. Their captions and controls depend on YouTube and on each video.
  • The mannequin and clothes are illustrations. They have a text description of what the mannequin wears, but not a detailed description of each drawing.

This is a student project, so the checks above are what the author could do. If something does not work for you, the author would like to know.
