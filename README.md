# ARCHIVE: A Museum of Fashion (1990-2009)

A virtual fashion museum for students and enthusiasts to explore the designers, runway shows and models of the 1990s and 2000s.

**Live site:** https://giuliaiglesias.github.io/fashion_archive/ (after GitHub Pages is enabled)

## Built with
Plain HTML, CSS and JavaScript (no frameworks). Each designer, runway show and model has its own HTML page.

## Project files
- `PROJECT_MEMORY.md`: decisions and changes from the original proposal
- `SOURCES.md`: sources, image credits and acknowledgements
- `TESTING.md`: test checklist and results

## Status
In progress. Done: Designers (9), Runways (9) and Models (9). Still to build: Timeline, Mannequin Room, Search, photos and videos.
